EMBASSY OF FAITH WORLDWIDE — VISUAL RESTRUCTURE

This package refreshes the church website using the existing navy, royal blue, gold and white identity. The layout direction is inspired by the supplied Amazing Grace Family Care Foundation reference: a strong photo-led opening, clear introduction, visual topic cards, a community/mission section and a direct invitation to connect. The design and copy are adapted for Embassy of Faith Worldwide rather than copied from the foundation site.

FILES
- index.html: redesigned homepage with layered hero, welcome strip, church introduction, mandate/ministries/messages cards, church-life imagery, visit information and closing calls to action.
- church.html, mandate.html, ministries.html, messages.html, events.html, gallery.html, visit.html: supporting pages.
- style.css: shared responsive visual system and styling.
- script.js: mobile navigation, theme toggle, events view selector, contact email hand-off and back-to-top button.
